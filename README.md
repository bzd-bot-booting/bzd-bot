# 🚆 Telegram-бот для мониторинга билетов БЖД

Этот Telegram-бот предназначен для автоматического поиска и мониторинга наличия билетов на поезда Белорусской железной дороги (БЖД) через сайт [pass.rw.by](https://rw.by).

Бот работает без авторизации в личном кабинете, используя браузерную автоматизацию (Playwright) для парсинга актуального расписания. Он умеет искать поезда по названиям станций, определять количество свободных мест по классам (плацкарт, купе, сидячие) и присылать уведомления, как только места появятся в продаже.

## ✨ Возможности

* **Современный интерфейс (aiogram-dialog):** Удобное пошаговое меню с кнопками «Назад» и «Отмена».
* **Умный поиск:** Ввод названий станций вручную или выбор из популярных городов.
* **Детальный парсинг:** Бот показывает время отправления/прибытия и раскладывает количество мест по типам (Плацкарт, Купе, Сидячий и т.д.).
* **Фоновый мониторинг:** Если мест на нужный поезд нет, бот запускает фоновую задачу (каждые 30 секунд), которая следит за появлением мест.
* **Очередь подписчиков:** Несколько пользователей могут ждать один и тот же поезд, уведомление получит первый в очереди.
* **Защита от спама:** Бот блокирует повторные нажатия кнопок, пока обрабатывается предыдущее действие.

## 🛠️ Требования

* Python 3.10 или выше (для локального запуска).
* Docker (для развертывания на сервере).
* Токен Telegram-бота (получить можно у [@BotFather](https://t.me)).

## 🚀 Локальный запуск (Windows / macOS / Linux)

1. Клонируйте репозиторий и перейдите в папку:
   ```bash
   git clone https://github.com
   cd bzd-bot
   ```

2. Создайте виртуальное окружение и активируйте его:
   * **Linux / macOS:**
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     ```
   * **Windows:**
     ```bash
     venv\Scripts\activate
     ```

3. Установите зависимости и браузер:
   ```bash
   pip install --upgrade pip
   pip install -r requirements.txt
   playwright install chromium
   ```

4. Запустите бота:
   ```bash
   python bot_auto.py
   ```
   *(По умолчанию бот запустится с открытым окном браузера для отладки).*

## ☁️ Развертывание на сервере (Docker / Amvera)

Проект полностью подготовлен для работы на облачных серверах (VPS, Amvera и т.д.) без графического интерфейса.

### Переменные окружения
В коде настроено чтение переменных. На сервере вам нужно задать:
* `TELEGRAM_BOT_TOKEN` — ваш токен от BotFather.
* `HEADLESS` — должно быть `True` (чтобы браузер работал невидимо).

### Docker
В репозитории есть готовый Dockerfile. Он автоматически установит Python, системные библиотеки для Chromium и запустит бота.
```bash
docker build -t bzd-bot .
docker run -d -e TELEGRAM_BOT_TOKEN="ваш_токен" -e HEADLESS="True" bzd-bot
```

### Amvera
Просто подключите этот репозиторий (ветку `main`), добавьте секрет `TELEGRAM_BOT_TOKEN` в настройках проекта, и Amvera соберет проект по инструкции из `amvera.yml`.

## ⚠️ Важно знать

* Бот не обходит капчу. Если сайт БЖД потребует ввода капчи, вам придется сделать это вручную.
* Сайт БЖД может периодически менять верстку. Если бот перестанет находить поезда или места, потребуется обновить CSS-селекторы в функции `parse_train_row`.
