# 🚆 Telegram-бот для мониторинга билетов БЖД

Этот Telegram-бот предназначен для автоматического поиска и мониторинга наличия билетов на поезда Белорусской железной дороги (БЖД) через сайт `pass.rw.by`. 

Бот работает без авторизации в личном кабинете, используя браузерную автоматизацию (Playwright) для парсинга актуального расписания. Он умеет искать поезда по названиям станций, определять количество свободных мест по классам (плацкарт, купе, сидячие) и присылать уведомления, как только места появятся в продаже.

## ✨ Возможности

- **Удобный интерфейс**: Выбор популярных городов и дат (сегодня, завтра, послезавтра) через inline-кнопки в Telegram.
- **Умный поиск**: Ввод названий станций вручную (словарь `SMART_STATIONS` автоматически подставляет правильные названия).
- **Детальный парсинг**: Бот показывает время отправления/прибытия и раскладывает количество мест по типам (Плацкарт, Купе, Сидячий и т.д.).
- **Фоновый мониторинг**: Если мест на нужный поезд нет, бот запускает фоновую задачу (каждые 30 секунд), которая следит за появлением мест, не блокируя диалог.
- **Остановка мониторинга**: Как только поезд отправляется или места появляются, мониторинг автоматически завершается с уведомлением пользователя.

## 🛠️ Требования

Перед запуском убедитесь, что у вас установлены:
- **Python 3.10** или выше.
- **pip** (менеджер пакетов Python).
- **Токен Telegram-бота** (получить можно у [@BotFather](https://t.me/BotFather)).

## 🚀 Локальная установка и запуск (Linux / Kali / macOS)

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/ваш_ник/bzd-bot.git
cd bzd-bot
```
   
2. **Создайте виртуальное окружение и активируйте его:**
```bash
python3 -m venv venv
source venv/bin/activate
```
*(Для пользователей Windows: `venv\Scripts\activate`)*

3. **Установите Python-зависимости:**
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

4. **Установите браузер Chromium и системные библиотеки (только для Linux):**
```bash
playwright install --with-deps chromium
```
*(Если вы не на Linux, просто выполните `playwright install chromium`)*

5. **Настройте токен:**
Откройте файл `bot_auto.py` и найдите строку:
```python
API_TOKEN = "ВАШ_ТОКЕН_ОТ_BOTFATHER"
```
Замените текст в кавычках на ваш реальный токен от BotFather.

6. **Запустите бота:**
```bash
python bot_auto.py
```
